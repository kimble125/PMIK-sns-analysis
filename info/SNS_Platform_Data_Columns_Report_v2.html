🔄 플랫폼별 이름만 다른 동일 역할 컬럼 (통합 가능)

아래 컬럼들은 플랫폼마다 이름은 다르지만 같은 역할을 합니다. 데이터 통합 시 하나로 합칠 수 있습니다.

통합 역할 (한글) 플랫폼별 컬럼명
📌 게시물 고유번호 블로그: post_id 카페: article_id 밴드: post_id 유튜브: video_id 카카오: shortcode
🏠 공간/채널 고유번호 블로그: blog_id 카페: cafe_id 밴드: entity_id 유튜브: channel_id 카카오: user_id
🏷️ 공간/채널 이름 카페: cafe_name 밴드: entity_name 유튜브: channel_name
👤 작성자 이름/닉네임 카페: author_nickname 밴드: author_nickname 인스타: handle 페이스북: user_name 카카오: name
🔗 게시물 주소(URL) 블로그: url 카페: url 밴드: url 유튜브: url 인스타: permalink
🖼️ 미디어 개수 인스타: media_count 페이스북: media_count 카카오: media_count

⭐ 플랫폼 고유 컬럼 (해당 플랫폼에서만 수집)

아래는 해당 플랫폼에서만 존재하거나 의미있는 고유 데이터입니다.

📗 네이버 (블로그+카페)

  • PM키워드 포함여부 is_pm_keyword
  • 카페 종류 cafe_type
  • 공개 여부 is_public
  • 블로거 소개글 profile_intro

🎵 밴드 (Band)

  • 밴드/페이지 구분 entity_type
  • 발견 검색어 search_keyword
  • PM키워드 포함여부 is_pm_keyword

📺 유튜브

  • 영상 길이 duration
  • 구독자 수 subscriber_count
  • 유튜브 태그 tags
  • 썸네일 OCR 텍스트 thumbnail_text_ocr
  • 영상 시작화면 OCR video_start_frame_ocr
  • 영상 종료화면 OCR video_end_frame_ocr
  • OCR에서 추출한 전화번호 *_phone_ocr
  • OCR에서 추출한 파트너번호 *_partner_ocr

📷 인스타그램

  • 미디어 종류 media_type
  • 본문 글자수 content_count
  • 해시태그 개수 hashtag_count

📘 페이스북

  • 공유 수 share_count
  • 음성 인식 결과 audio_caption
  • 이미지 OCR 결과 media_caption

💛 카카오스토리

  • 미디어 종류 media_type
  • 이미지 OCR 결과 media_caption
  • 수집 순번 p_num

💡 핵심 요약

✅ 공통 7개: 본문, 작성일시, 좋아요, 댓글, 해시태그, 이미지/동영상 주소
🔄 통합 가능 6개: 게시물ID, 공간ID, 공간이름, 작성자, URL, 미디어개수
📺 유튜브 강점: OCR로 영상 내 텍스트 자동 추출 (전화번호, 파트너번호)
⚠️ 개선 필요: 해외 SNS(인스타/FB/카카오)에 PM 정보 추출 기능 추가
