## [2025-11-26] 네이버 블로그 크롤러 v10.4

### 🐛 버그 수정
1. **Profile URL 버그 수정** (치명적)
   - 이전: `ProlieOf.nhn` (오타)
   - 수정: `ProfileOf.nhn` (정상)
   - profile_intro 수집률 0%의 근본 원인

### ✨ 새 기능
1. **PaddleOCR로 교체**
   - EasyOCR → PaddleOCR (한국어 인식 성능 향상)
   - 신뢰도 0.6 이상 텍스트만 수집
   
2. **배제 데이터 수집 시스템**
   - `ExcludedDataManager` 클래스 추가
   - 배제된 게시물을 JSON/CSV로 저장
   - 필터링 검증 가능

3. **복합 키워드 AND 로직**
   - `피엠코리아+침대`: 두 단어가 모두 있을 때만 배제
   - config.yaml에서 `+` 기호로 연결

### 🔧 개선
1. **콘텐츠 타입 분류기 분리**
   - `analysis/content_type_classifier.py`로 이동
   - 크롤러는 원시 데이터만 수집

2. **연도 확장 모든 키워드 적용**
   - 기존: primary 키워드만
   - 변경: 모든 키워드에 2018-2025 연도 확장

3. **한국 시간(KST) 고정**
   - pytz 사용
   - 모든 timestamp에 KST 적용

4. **리포트 시스템 개선**
   - 단일 파일(`data/naver_blog_reports.txt`)에 누적
   - 더 많은 통계 항목 추가

5. **클래스 이름 변경**
   - `VMLoggingManager` → `SessionLoggingManager`
   - VM/로컬 모두 지원 명시

### ⚠️ TEST 버전 전용
- API 요청 제한: 키워드당 100개
- 실행 시간 제한: 40분

## [2025-11-25] AI 도구 도입 검토 및 프로젝트 개선 방안

### 🔍 분석 완료

- **현재 Windsurf**: ✅ 유지 (기존 유지보수용)
