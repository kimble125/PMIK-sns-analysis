# 📈 수집량 개선 가이드

## 현재 상황

**문제:** 필터링 과다로 수집량 부족
- 이전 v10.1: 717건 API 결과 → 3건 최종 수집 (2시간 실행)
  - 주의: 717건은 "키워드당 300건 × 여러 키워드"가 아님
  - 2시간 동안 일부 키워드만 처리된 결과
  - API 검색 결과 자체가 적었거나 필터링이 과도했음
- 목표: 수천 개 이상 수집

**v10.2 개선사항:**
- 필터링 기준 완화: 제외 키워드 2개 → 4개
- PM 브랜드 키워드 정제
- 키워드 확장 최적화 (2018-2025, 8년)
- 키워드당 500건으로 증가

**v10.2 예상 개선:**
- 800~2,000개 수집 (2시간 실행)
- 실제 결과는 테스트 후 확인 필요

- ⚠️ 노이즈 약간 증가 (후처리로 제거 가능)
- 📊 근거: v10.1에서 2→4로 완화 시 필터링 크게 감소

## ⚠️ 주의사항

### 1. 네이버 API 제한
- 키워드당 검색 결과 제한 (1000건)
- 과도한 요청 시 차단 가능
- → 적절한 딜레이 유지 필수

### 2. VM 리소스
- 메모리 사용량 증가
- 장시간 실행 시 안정성 확인
- → 주기적인 체크포인트 저장

### 3. 데이터 품질
- 수집량 증가 = 노이즈 증가
- → 후처리 필터링 필요
- → 분석 시 품질 검증 필수

### 4. 법적/윤리적 고려
- 저작권 존중
- 개인정보 보호
- → 수집 데이터 사용 목적 명확히
