# 키워드 수집 전략 설명

## 질문: 키워드당 300건 수집 후 다시 첫 키워드부터 수집 가능한가?

### 답변: **현실적으로 어렵습니다** ❌

---

## 🔍 네이버 블로그 API의 제약

### 1. 검색 결과 제한
```
키워드당 최대 1000개까지만 검색 결과 제공
- start=1부터 start=1000까지
- 1000개 이상은 접근 불가
```

### 2. 정렬 순서 고정
```
검색 결과는 관련성 순으로 정렬
- 시간이 지나도 동일한 순서
- 새로운 게시물이 추가되지 않는 한 결과 동일
```

### 3. 시간별 필터링 불가
```
네이버 블로그 API는 날짜 범위 지정 불가
- "2024-01-01 ~ 2024-12-31" 같은 필터 없음
- 따라서 "이미 수집한 것 제외" 불가능
```

---

## 💡 해결 방법: 키워드당 500건으로 설정

### 왜 500건인가?

**v10.2 설정:**
```yaml
keywords:
  primary:
    - keyword: "피엠인터내셔널"
      target: 500  # ← 여기
```

**이유:**
1. **더 많은 키워드 커버**
   - 300건: 96개 키워드 × 300 = 28,800건 요청
   - 500건: 96개 키워드 × 500 = 48,000건 요청
   
2. **필터링 감안**
   - 500건 요청 → 약 100~200건 실제 수집
   - 필터링 60~80% 예상

3. **2시간 내 완료 가능**
   - 게시물당 3~5초
   - 500건 × 5초 = 2,500초 ≈ 42분/키워드
   - 2시간 내 2~3개 키워드 완료 가능

## 🔄 중복 방지는 어떻게?

### 현재 구현된 중복 체크

```python
# 1. URL 기반 중복 체크
if duplicate_checker.is_duplicate(url=normalized_url):
    continue

# 2. 콘텐츠 지문 기반 중복 체크
fingerprint = hashlib.md5((title + content[:200]).encode()).hexdigest()
if duplicate_checker.is_duplicate(fingerprint=fingerprint):
    continue
```

**효과:**
- 같은 URL: 자동 제외 ✅
- 같은 내용: 자동 제외 ✅
- 다른 키워드에서 발견된 게시물: 자동 제외 ✅

## ❓ 만약 "다시 첫 키워드부터" 구현하려면?

### 방법 1: 두 번째 실행 (권장) ✅
```bash
# 첫 번째 실행 (2시간)
python3 pm_naver_blog_crawler_v10_2_test.py

# 두 번째 실행 (추가 2시간)
# → 자동으로 중복 제외하고 새로운 것만 수집
python3 pm_naver_blog_crawler_v10_2_test.py
```

**장점:**
- 간단
- 중복 자동 제거
- 안전

### 방법 2: 코드 수정 (복잡) ⚠️
```python
# 키워드 반복 수집
rounds = 2  # 2회 반복
for round_num in range(rounds):
    for kw_info in ALL_KEYWORDS:
        keyword = kw_info["keyword"]
        target = 250  # 500 / 2
        # 수집 로직...
```

**단점:**
- API 요청 중복
- 시간 낭비 (같은 결과)
- 효과 미미

### 방법 3: 시간 기반 키워드 (불가능) ❌
