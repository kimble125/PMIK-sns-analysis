# PM 네이버 블로그 크롤러 v10.1 - 20분 테스트 실행 가이드

## 🎯 테스트 목적
v10.1의 새로운 기능들을 20분 동안 테스트하고 상세한 결과 보고서를 생성합니다.

### v10.1 신규 기능
1. **📅 키워드 연도 확장**: 모든 키워드에 2023~2025 자동 추가 (키워드 3배)
2. **키워드당 50개 수집**: 연도별로 최신 데이터 확보
3. **프로필 정보 수집**: 닉네임, 소개글, 회원번호, URL
4. **이미지 OCR 처리**: 추천인 정보 추가 추출
5. **19가지 콘텐츠 타입 분류**: 다중 분류 지원
6. **20개 추가 분석 컬럼**: 상세한 데이터 분석 지원
7. **상세 결과 보고서**: 성능 지표 자동 생성

## 🚀 실행 방법

### 1. 테스트 모드 확인
`config.yaml` 파일에서 테스트 모드가 활성화되어 있는지 확인:

```yaml
test_mode:
  enabled: true  # 테스트 모드 활성화
  max_duration_minutes: 20  # 20분 제한
  max_posts: null  # 무제한 (시간으로만 제한)
```

### 2. 실행
```bash
python pm_naver_blog_crawler_v10_1_test.py
```

### 3. 진행 상황 모니터링
- 실시간 로그로 진행 상황 확인
- 20분 경과 시 자동 종료 (진행 중인 수집 완료 후)
- 체크포인트 자동 저장 (1시간마다, 단 20분 테스트에서는 발생 안 함)

## 🔍 예상 결과 (20분 테스트)

### 키워드 확장 효과
- **원본 키워드**: 예: 10개
- **연도 확장 후**: 10개 × 3년 = 30개
- **키워드당 목표**: 50개
- **이론적 최대**: 30개 × 50개 = 1,500개 (하지만 20분 제한)

### 수집 예상치
- **예상 게시물 수**: 30~60개 (20분 제한)
  - OCR 사용 시: 30~40개 (느림)
  - OCR 미사용 시: 50~60개 (빠름)
- **다양한 연도 데이터**: 2023, 2024, 2025년 게시물 혼합
- **키워드 다양성**: 여러 키워드 × 여러 연도

- **게시물당 평균 시간**:
  - OCR 사용 시: 20~30초
  - OCR 미사용 시: 10~15초

### 성공률 예상치
- **성공률**: 60~80%
- **필터링률**: 15~25% (제외 키워드, 미디어 스타일)
- **중복률**: 5~10%
- **에러율**: 5~10%

### 신규 기능 성과 예상
- **프로필 수집률**: 70~90%
- **추천인 정보 수집률**: 50~70%
- **OCR 성공률**: 60~80% (이미지가 있는 경우)
- **콘텐츠 타입 분류율**: 95~100%

## ⚠️  주의사항

### 1. OCR 처리 속도
- 이미지 OCR은 게시물당 5~10초 추가 소요
- 20분 테스트에서는 약간의 속도 저하 감수

### 2. 프로필 정보 수집
- 프로필 페이지 접근으로 게시물당 1~2초 추가
- 네이버 차단 방지를 위해 속도 조절 유지

### 3. 시간 제한
- 20분 경과 시 **진행 중인 수집까지만 완료**
- 키워드 루프와 개별 게시물 수집 시작 전에 시간 체크
- 안전한 종료 보장

### 4. 네트워크 상태
- 불안정한 네트워크 시 재시도 로직 작동
- 에러 발생 시에도 보고서 생성됨

## 🐛 트러블슈팅

### 문제: OCR이 너무 느림
**해결**: OCR 비활성화 후 재실행
```bash
pip uninstall easyocr
python pm_naver_blog_crawler_v10_1_test.py
```

### 문제: 20분 전에 종료됨
**원인**: 
- API 키 문제
- 네트워크 오류
- 메모리 부족

**확인**:
- `vm_crawler_log.json` 확인
- 로그 파일 확인

### 문제: 보고서가 생성되지 않음
**원인**: 수집된 게시물이 없음

**확인**:
- 키워드 설정 확인
- API 키 확인
- 필터링 조건 확인

## 📊 결과 분석 가이드

### 1. 성공률 분석
- **60% 이상**: 정상
- **40~60%**: 필터링 조건 확인 필요
- **40% 미만**: API 키 또는 네트워크 문제

### 2. OCR 성공률 분석
- **70% 이상**: 정상
- **50~70%**: 이미지 품질 문제 가능
- **50% 미만**: OCR 설정 확인 필요

### 3. 콘텐츠 타입 분류
- **95% 이상 분류**: 정상
- **80~95%**: 일부 게시물 특수 케이스
- **80% 미만**: 키워드 패턴 확인 필요

### 4. 수집 속도
- **2~4개/분 (OCR 사용)**: 정상
- **4~6개/분 (OCR 미사용)**: 정상
- **1개/분 미만**: 성능 문제
