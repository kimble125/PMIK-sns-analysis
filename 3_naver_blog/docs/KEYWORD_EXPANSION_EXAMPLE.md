# 키워드 연도 확장 예시

## 📅 v10.1 키워드 연도 자동 확장

### 작동 방식

모든 키워드에 2023, 2024, 2025 연도를 자동으로 붙여서 확장합니다.

### 확장 전 (config.yaml)

```yaml
keywords:
  primary:
    - keyword: "피엠인터내셔널"
      target: 60
    - keyword: "피트라인"
      target: 60
    - keyword: "PM International"
      target: 60
  
  secondary:
    - keyword: "파워칵테일"
      target: 40
    - keyword: "액티바이즈"
      target: 40
```

**총 키워드**: 5개

---

**총 키워드**: 15개 (5개 × 3년)

## 💡 효과

### 1. 연도별 데이터 확보
- 2023년 게시물
- 2024년 게시물
- 2025년 게시물 (최신)

### 2. 시간 경과 분석 가능
- 연도별 트렌드 변화
- 제품별 언급 추이
- 시즌별 패턴 분석

### 3. 데이터 다양성 증가
- 키워드 × 연도 조합
- 더 폭넓은 게시물 수집
- 필터링된 게시물 감소

## 📈 실제 검색 예시

### 네이버 블로그 검색
```
"피엠인터내셔널 2023" 검색
→ 2023년 관련 게시물 우선 표시

"피엠인터내셔널 2024" 검색
→ 2024년 관련 게시물 우선 표시

"피엠인터내셔널 2025" 검색
→ 2025년 최신 게시물 우선 표시
```

### 검색 결과 차이
- **연도 없이 검색**: 최신순 정렬 (주로 2025년)
- **연도와 함께 검색**: 해당 연도 게시물 집중

---

## ⚠️  주의사항

### 1. 연도가 제목/본문에 없는 경우
일부 게시물은 검색되지만 연도가 명시되지 않을 수 있습니다.  
→ 이런 경우에도 `published_datetime`으로 연도 파악 가능

### 2. 중복 가능성
같은 게시물이 여러 연도 검색에 걸릴 수 있습니다.  
→ 크롤러의 중복 체크 시스템이 자동 제거

### 3. 키워드 수 증가
키워드가 3배로 늘어나므로 전체 실행 시간도 비례해서 증가할 수 있습니다.  
→ 20분 테스트는 일부 키워드만 처리
