# 🚀 Google Colab YouTube 크롤러 완전 가이드

## 📊 RAM 및 GPU 설정 방법

### 1️⃣ 런타임 설정 (필수!)

**상단 메뉴에서:**
```
런타임 > 런타임 유형 변경
```

**권장 설정:**
- **하드웨어 가속기**: `GPU` (T4 권장)
- **런타임 모양**: `고용량 RAM` (25.5GB)

### 2️⃣ RAM 설정 옵션

| 옵션 | RAM | 용도 |
|------|-----|------|
| **표준** | 12.7GB | 기본 (충분함) |
| **고용량 RAM** | 25.5GB | 권장 (안정적) |
| **프리미엄** | 51GB | 대용량 처리 |

### 3️⃣ GPU 설정 이유

- **Whisper AI**: GPU 사용시 5-10배 빠름
- **EasyOCR**: GPU 사용시 3-5배 빠름
- **45분 제한**: GPU 없으면 시간 부족

## ⚙️ 런타임 설정 확인 코드

```python
# GPU 확인
!nvidia-smi

# RAM 확인
!cat /proc/meminfo | grep MemTotal
```

## 🎯 권장 설정

**무료 사용자:**
- GPU: T4
- RAM: 고용량 RAM (25.5GB)

**Colab Pro 사용자:**
- GPU: A100 또는 V100
- RAM: 고용량 RAM
